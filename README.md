# CGE Experiments

Isolated engineering experiments for evaluating native technologies and runtime approaches around Codogma Engine.

## Experiments

- [Native Rust Brick Breaker](rust-brick-breaker/README.md) — a standalone SDL3 + wgpu + Flecs + Box2D v3 + miniaudio + QuickJS-NG + TypeScript proof of stack. It is intentionally independent of the production Codogma Engine repository and workspace.
