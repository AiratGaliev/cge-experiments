# CGE Experiments

Isolated engineering experiments for evaluating native technologies and runtime approaches around Codogma Engine.

## Experiments

- [Codogma Native 2D Runtime](rust-brick-breaker/README.md) — a scripting-first native 2D runtime vertical slice using Rust, SDL3, wgpu, Flecs, Box2D v3, miniaudio and QuickJS-NG. The Brick Breaker sample game is authored in TypeScript and runs inside QuickJS; Rust provides reusable engine services rather than game-specific gameplay.
